# QR Studio

Generador de códigos QR personalizado desarrollado con HTML, CSS y JavaScript. Funciona directamente en el navegador y permite personalizar el diseño antes de exportarlo.

## Funciones actuales

- Generación y actualización del QR en tiempo real.
- Texto o URL como contenido.
- Personalización de color del QR y fondo.
- Tamaño y margen configurables.
- Niveles de corrección de error L, M, Q y H.
- Estilos de puntos y esquinas.
- Presets visuales: clásico, morado, invertido, suave y neón.
- Carga y eliminación de logo.
- Control del tamaño y margen del logo.
- Descarga en PNG y SVG.
- Copia del PNG al portapapeles cuando el navegador lo permite.
- Interfaz adaptable para escritorio y móvil.
- Validación básica del contenido y del archivo de logo.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- [qr-code-styling](https://github.com/kozakdenys/qr-code-styling)

## Uso

Abre `index.html` en un navegador moderno. No requiere servidor ni instalación de dependencias.

> Nota: la interfaz funciona localmente, pero la biblioteca `qr-code-styling` se carga desde un CDN, por lo que la primera carga requiere conexión a Internet.
